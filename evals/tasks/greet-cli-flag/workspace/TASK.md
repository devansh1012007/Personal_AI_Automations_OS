# Task: greet-cli-flag

`greeter.py` is a one-argument greeting CLI. Give it an optional
`--shout` flag: when present, the printed greeting is upper-cased and
gains one extra exclamation mark — `greeter Ada --shout` prints
`HELLO, ADA!!` where `greeter Ada` prints `Hello, Ada!`. The flag is
off by default and the plain path must not change. The attached suite
under `tests/` is the contract.
