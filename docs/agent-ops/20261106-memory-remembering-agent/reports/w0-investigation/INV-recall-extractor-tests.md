## 6. Risks (ranked)
1. **Worker narrative leak via touch (high).** Touching `_hot_facts` results pre-filter `[VERIFIED src/paa/agents/context_agents.py:352-353]` would advance `last_queried_at`/`use_count` for narrative facts the worker never saw, retaining them and silently leaking retention signal across the security boundary the module exists to enforce (`[VERIFIED src/paa/agents/context_agents.py:98-105]`). Mitigation: touch post-filter (worker) / post-gatherer (planner) or pass a flag; update the read-only docstring explicitly; add a test that narrative `use_count` is unchanged by worker recall.
2. **Double-touch on hot∩semantic overlap (med).** Same fact returned by both tiers would be incremented once per tier (or twice per `touch_many` if list contains dup ids — `execute_many` increments per row). Mitigation: `set(ids)` before `touch_many`; T04 asserts `+1` not `+2`.
3. **Graph synthetic ids must never touch (med).** `_graph_neighbours` ids are `graph:{entity}:{n}` `[VERIFIED src/paa/agents/context_agents.py:282]` — touching them updates 0 rows (harmless but masks bugs).
