**DECISION D-FORMULA (ADR-0040 silent on equation shape).** ADR-0040 states only utility=0→inf, threshold positive scale, suggestion on crossing. No equation is named. I implement `total = (storage+retrieval+noise+maintenance)/utility` for utility>0, `inf` for utility==0 (raw division never evaluated, mirrors ADR-0012 (1+P)(1+R) precedent). Threshold is therefore a ratio (cost per unit utility); alternative additive `sum - utility` cannot yield inf at utility=0, and epsilon-guard `sum/(utility+eps)` is explicitly rejected by ADR-0040:38-42. Recorded so reviewer can overturn.
**DECISION D-DERIVATIONS (ADR-0040 source gaps).** ADR-0040:44-56 requires named derivation or explicit unavailable for storage/maintenance, forbids silent 0/1. Pure function takes all five terms as inputs (derivation is caller's job); curator supplies named derivations from stored columns only (no timestamps, no new producers): storage=row-share `1.0/N` (N=live count, ADR-named); retrieval=`1/(1+use_count)` (reuse amortises retrieval); noise=`1-importance`; maintenance=`1-initial_confidence` (decay-sweep adjacency — low stored confidence costs upkeep); utility=`importance*initial_confidence`. All computed per fact, O(1)/fact, keyset-batched. Terms are *not* silently zero: each is a named transform of a real column, documented in code; `utility=0` (importance=0 or confidence=0) → inf → suggestion. Tradeoff: proxies are not measured byte/token costs — noted as limitation; operator tunes threshold. Alternative "mark unavailable + exclude loudly" rejected for curator because stored-column derivations exist and excluding would make total a 2-term function contradicting the 5-term contract; pure function still accepts storage/maintenance=0 boundary as *measured zero*, distinct from unavailable.
**Risks / edge cases.** (a) Overflow: finite huge inputs sum to inf (never NaN — utility finite so inf/utility=inf). (b) Hostile negative/NaN/inf inputs → ValueError via _finite/_non_negative (never NaN per brief; ADR silent → ValueError). (c) inf threshold (allowed by gt=0) → only inf totals suggest. (d) N=1 storage=1 makes ideal fact total≈1+ → threshold tuning is operator job; gate disabled by default so inert until tuned. (e) Unbounded scan → mitigated by keyset pagination (batch_size, ORDER BY id unique tie-break per AGENTS). (f) dry_run: cost gate runs in dry_run too (writes nothing; preview shows suggestions) — DECISION, documented; analyze() stats still suppressed in dry_run.
**Expected behavior.** Disabled → zero suggestions, zero total_memory_cost calls. Enabled + utility=0 fact → `cost_gate.suggestions` log + report list entry, fact row still exists. Enabled + finite total >= threshold → suggestion; < threshold → none. Same inputs twice → same float (deterministic, idempotent). No DELETE anywhere in diff.
**Required tests (fail-before, pass-after).** Metrics unit (known values, utility=0 inf, boundary 0, hostile negative/NaN/inf → ValueError, huge → finite/inf never NaN, Hypothesis finite-or-inf/never-NaN + monotonic in utility) + curator integration (enabled utility=0 → suggestion + fact remains + log line; disabled → none + zero calls via spy; finite above/below threshold; idempotency double-run same list + count unchanged; dry_run still suggests).
