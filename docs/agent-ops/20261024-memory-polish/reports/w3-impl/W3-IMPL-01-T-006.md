# Implementation report — W3-IMPL-01 — T-006 optional LLM summarizer for ContextCompactor

## 1. Task and acceptance criteria (restated)

Task T-006 (P-006): Add an optional LLM-backed summarizer to `ContextCompactor` in
`src/paa/context/compaction.py`. The compactor is deterministic and non-LLM by
default; this change adds an optional injected `summarizer` callable (`str -> str`)
that further compresses text after mechanical reduction, preserving the mechanical
default when no summarizer is provided. Also create
`tests/context/test_llm_compaction.py` proving the optional summarizer path and the
mechanical default.

Acceptance criteria (brief §3):
1. `ContextCompactor.__init__` accepts optional `summarizer` parameter (callable
   `str -> str`).
2. When `summarizer` is None (default): behavior unchanged — purely mechanical,
   deterministic.
3. When `summarizer` is provided: `compact()` calls it after mechanical fixed-point
   reduction; result is the summarizer's output.
4. `__slots__` includes `summarizer`.
5. Mechanical default still idempotent (`compact(compact(x)) == compact(x)`).
6. With summarizer: summarizer called exactly once per `compact()` call.
7. Scoped: `pytest tests/context/test_llm_compaction.py -q` green; `ruff check
   src/paa/context tests/context` -> 0; `mypy src/paa/context` -> 0.

WRITE-SET: `src/paa/context/compaction.py`, `tests/context/test_llm_compaction.py`.
READ-ONLY: `src/paa/context/gatherer.py` (W3-IMPL-02). FORBIDDEN: all other context

## 3. Root cause

No root-cause defect — this is additive surface. The compactor was designed
(RFC §1.5 determinism, circularity, fidelity per module docstring) to be purely
mechanical; the roadmap now asks for an opt-in LLM summarizer. The fix is to inject
a callable seam behind a default of `None`, preserving the existing mechanical path
byte-for-byte when absent, rather than hard-coding a model call or making
summarisation mandatory.

## 4. Approach chosen and why

**Chosen:** optional constructor parameter `summarizer: Callable[[str], str] | None =
None`, stored in the new `__slots__` entry `"summarizer"`. `compact()` runs the
unchanged mechanical fixed-point loop, then — only when `self.summarizer is not
None` — invokes it exactly once on the mechanical fixed point and returns its
output. With `None` the method returns the mechanical result exactly as before.

**Alternatives rejected:**
- Make summarisation mandatory / default-on: rejected — violates the deliberate
  mechanical default (docstring reasons 1-3) and brief AC #2.
- `try/except` fallback to mechanical path when the summarizer raises: rejected —
  brief AC #3 states "result is the summarizer's output" (unconditional), and
  Plan1 line 204's fallback cites `world_model.py:210-220` which is outside my
  write-set and appears to be a stale cross-reference; adding exception handling
  would change the contract in a way the brief does not authorize. A summarizer
  that raises propagates, matching the "fail loud" convention for injected
  callables.
- Post-compaction re-compaction of the summarizer output: rejected — summarizer
  output is the final result (AC #3); re-running mechanical rules on it is not
  specified and could alter the summarizer's text.

This addresses the cause (no LLM seam exists) not a symptom, and is fully
additive/backward compatible.

## 8. Long-run test

- **Source:** behavior derived from brief ACs and Plan1 C06/C12; verified against
  actual `compaction.py` source (read, not assumed).
- **Load (100x/concurrence/partial failure):** not applicable — `compact()` is a

  accepted), proving the tests test the fix.

## 9. Edge cases and abuse scenarios

Handled: empty string (summarizer still invoked once on `""`); summarizer returns
longer text (passes through — opt-in, non-expansion waived); summarizer returns
non-str (type error at call boundary, caller's contract); `max_line_chars`/`ellipsis`
validation unchanged (summarizer is orthogonal).
Consciously not handled: summarizer exceptions (propagate, per AC #3 and
"fail loud" convention); summarizer output not re-compacted (not specified).
Unknown: none within scope.
